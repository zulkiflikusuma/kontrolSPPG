# 🍱 SPPG Pekiringan - FieldOps

> Aplikasi Asisten Lapangan SPPG Pekiringan - MBG | Dibuat oleh Zull - Lulusan IT

Live: https://zulkiflikusuma.github.io/sppg-pekiringan-fieldops/

### Fitur
- Dashboard porsi harian Pekiringan (1.245)
- Distribusi foto + GPS + tanda tangan (audit ready)
- Stok & QC checklist
- Laporan BGN export CSV + WA
- Offline-first + Installable PWA

### Install di HP
1. Buka link demo di Chrome HP
2. Popup Install akan muncul -> Klik Install
3. Atau titik tiga -> Add to Home Screen
4. Ikon SPPG Pekiringan muncul kayak aplikasi asli!

### Tech
HTML5 + Tailwind + PWA + LocalStorage + Supabase (optional)

### Struktur
index.html = V1 Cantik (main)
v2-kerja.html = V2 Kerja real
manifest.json + sw.js = PWA
icon-*.png = Icon
schema.sql = DB Supabase
